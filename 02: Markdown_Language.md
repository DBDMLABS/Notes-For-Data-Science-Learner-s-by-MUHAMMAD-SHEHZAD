### Headings

> Heading 1 → `# Text`\
> Heading 2 → `## Text`\
> Heading 3 → `### Text`\
> And so on...

---

### Block of Words

> Use `>` before the text.

> `> Line 1`\
> `> Line 2`\
> `> Line 3`

> Use `\` for a line break.

---

### Line Break

> `\` → Line break\
> `---` then press enter → Horizontal line

---

### Headings with Block of Words

> `> # Heading 1`\
> `> ## Heading 2`\
> `> ### Heading 3`\
> and upto so on...

---

### Face of Text

> 1. Bold → `**Text**`
> 2. Italic → `*Text*`
> 3. Bold & Italic → `***Text***`
> 4. Underscore can also be used: `__Text__`, `_Text_`, `___Text___`

---

### List & Bullet Points

> `1. Text` → Numbered list\
> `- Text` → Bullet list\
> `Tab` → Sub-bullet\
> `Shift + Tab` → Main bullet

---

### Links & Hyperlink Text

> `[Link Text](link)`\
> No space between `]` and `(`.

---

### Inserting Image

> `![Image Text](image.png)`\
> Online image:\
> `![Image Text](image-link)`\
> ! This sign used to display image.

---

### Adding Code or Code Block

> Single line → `` `print(x)` ``\
> Code block:

### Adding Tables

> Use `|` to create columns.

```markdown
| A | B | C |
|---|---|---|
| 1 | 2 | 3 |
```
